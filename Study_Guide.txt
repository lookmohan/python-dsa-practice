## 11. Sort 0s, 1s, 2s (Dutch Flag)

**code :**

```python
arr = [2, 0, 1, 2, 1, 0]

low = mid = 0
high = len(arr) - 1

while mid <= high:
    if arr[mid] == 0:
        arr[low], arr[mid] = arr[mid], arr[low]
        low += 1
        mid += 1
    elif arr[mid] == 1:
        mid += 1
    else:
        arr[mid], arr[high] = arr[high], arr[mid]
        high -= 1

print(arr)
```

**workflow :**

```
# Use 3 pointers: low, mid, high
# Swap based on value
# =====================================================
```

## 13. Rearrange Array (Max/Min)

**code :**

```python
arr = [1, 2, 3, 4, 5, 6]

result = []
left, right = 0, len(arr) - 1

while left <= right:
    if left != right:
        result.append(arr[right])
        result.append(arr[left])
    else:
        result.append(arr[left])
    left += 1
    right -= 1

print(result)
```

**workflow :**

```
# Use two pointers
# Pick max then min alternately
# =====================================================
```

## 16. Product of Array Except Self

**code :**

```python
arr = [1, 2, 3, 4]
n = len(arr)

left = [1]*n
right = [1]*n

for i in range(1, n):
    left[i] = left[i-1] * arr[i-1]

for i in range(n-2, -1, -1):
    right[i] = right[i+1] * arr[i+1]

result = [left[i] * right[i] for i in range(n)]

print(result)
```

**workflow :**

```
# Build prefix product array
# Build suffix product array
# Multiply both
# =====================================================
```
